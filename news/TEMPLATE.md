# 【カテゴリ】記事タイトルなんだぜ！

- **掲載日**: YYYY-MM-DD
- **出来事の日付**: YYYY-MM-DD
- **区分**: Tech News / GitHub Trending / Tomiya News
- **対象**: プロジェクト名やバージョン

## 何が起きたんだぜ？

検証済みの出来事を簡潔に書くんだぜ。
「リリースした」「発表した」「注目を集めた」は、それぞれ別の意味なんだぜ。

## 何が面白いんだぜ？

仕組み、背景、以前との違い、開発者にとっての意味を説明するんだぜ。

## まだ注意点もあるんだぜ

未実装、対応環境、破壊的変更、ライセンスなどを確認するんだぜ。
評価や予測は事実と分けるんだぜ。

## だからなんだぜ

読者にとっての一番大事なポイントをまとめるんだぜ。

### Sources

- [一次情報](https://example.com/) — 確認した公式情報なんだぜ
- [補助情報](https://example.com/) — 必要なら使うんだぜ
