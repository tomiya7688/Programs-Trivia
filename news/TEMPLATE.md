# 【カテゴリ】記事タイトルなんだぜ！

- **掲載日**: YYYY-MM-DD
- **出来事の日付**: YYYY-MM-DD
- **区分**: Tech News / GitHub Trending / Tomiya News
- **対象**: プロジェクト名やバージョン

## 何が起きたんだぜ？

まず「おいおい、これは大変だぜ！」くらいの勢いでつかんで、検証済みの出来事を分かりやすく書くんだぜ。
重大な事故でも堅苦しい報道調には変えないんだぜ。変な仕組みには軽くツッコんでも、被害者を笑いものにしたり根拠のない被害を盛ったりはしないぜ。
「リリースした」「発表した」「注目を集めた」は、それぞれ別の意味なんだぜ。

## 何が面白いんだぜ？

仕組み、背景、以前との違い、開発者にとっての意味を説明するんだぜ。

## まだ注意点もあるんだぜ

未実装、対応環境、破壊的変更、ライセンスなどを確認するんだぜ。
評価や予測は事実と分けるんだぜ。セキュリティ記事なら、発見・悪用・実被害や、脆弱性・更新事故の違いも混ぜないんだぜ。
セキュリティソフトに触れるなら、宣伝や万能論はやめるぜ。更新とバックアップ、誤検知や導入時の相性も大事なんだぜ。

## だからなんだぜ

読者にとっての一番大事なポイントをまとめるんだぜ。
