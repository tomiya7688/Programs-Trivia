# LLM企業はどこも赤字なんだぜ！？ ……と思ったら四半期黒字もあるんだぜ！

- **掲載日**: 2026-10-31
- **出来事の日付**: 2026-10-21〜29（Meta・Anthropic・Microsoft・Alphabet・Amazonの決算／財務情報公開）
- **確認日**: 2026-10-31
- **区分**: Tech News / 生成AI・企業財務
- **対象**: OpenAI、Anthropic、Microsoft、Alphabet、Amazon、Meta

## AIが世界中の仕事を変えるんだぜ！ ……ところで儲かってるんだぜ？

大規模言語モデル、**LLM** は猛烈な勢いで進化してるんだぜ。

ところがニュースを見ると、

> 売上がすごいんだぜ！
>
> データセンターにとんでもない額を投資するんだぜ！
>
> ……で、利益はどこなんだぜ？

という話も山ほど出てくるんだぜ。

**これは大変だぜ！**

でも「LLMを作ってる企業はどこも赤字」と言い切ると、2026年10月の資料では違うんだぜ。

**LLM専業企業、巨大テック企業の全社決算、クラウド部門、AIサービス単体の収支は、それぞれ別物**なんだぜ。

## OpenAIは売上が伸びても、計算代が大変なんだぜ

2026年6月の **The Information** の報道によると、OpenAIが投資家に共有したという2026年1〜3月期の数字は、

- **売上：約57億ドル** なんだぜ。
- **営業損失：約93億ドル** なんだぜ。
- **現金消費（cash burn）：約37億ドル** なんだぜ。

だというんだぜ。

おいおい、**売上57億ドルなのに営業赤字93億ドル**って、ものすごい研究開発と成長投資なんだぜ。

この報道では、サービス提供の原価を引いた **粗利益率は約39%** とも説明されているんだぜ。つまり「APIやサービスを動かすほど必ずその分だけ赤字になる」という単純な話ではないんだぜ。

ただし、**OpenAIのこの四半期の数字は公表済みの監査済み決算書から直接確認したものではなく、投資家向け資料を見たという報道**なんだぜ。Reutersも独立には確認できないと書いているぜ。

**売上、営業損失、現金消費は同じ数字ではない**んだぜ。

## Anthropicは上半期赤字……なのに4〜6月だけ見ると黒字なんだぜ！？

**2026年10月26日に米SECへ提出されたAnthropicのS-1資料**が、さらに面白いんだぜ。

| 期間と指標 | 金額（米ドル） |
| --- | ---: |
| 2026年1〜6月 売上 | **162.86億ドル** |
| 2026年1〜6月 営業損失 | **6.93億ドル** |
| 2026年1〜6月 純損失 | **807.48億ドル** |
| **2026年4〜6月 営業利益** | **+9.74億ドル** |

※上半期と四半期は別々の期間なんだぜ。どれもS-1のGAAPベースの数値なんだぜ。

**上半期は赤字なのに、4〜6月だけなら営業黒字なんだぜ！**

さらに、株式報酬などを除く **調整後営業利益（非GAAP）** は、上半期で **+16.18億ドル**、4〜6月期は **+22.35億ドル** と説明しているんだぜ。

ただし調整後の利益は、一般会計基準の営業利益と同じではないんだぜ。都合のいい数字だけ抜き出して「完全黒字化！」と騒ぐのも早いんだぜ。

## 純損失807億ドル！？ 何をそんなに燃やしたんだぜ？

この数字は衝撃的なんだぜ。

でも、**純損失807.48億ドル ＝ 現金807.48億ドルが燃えた** ではないんだぜ！

S-1によると、上半期の純損失のうち **723.88億ドル** は、転換社債や関連金融商品の**公正価値の変動による会計上の費用**なんだぜ。

企業価値や資本調達の条件が変わると、転換社債などの評価額も変化して、会計上大きな損失になる場合があるんだぜ。

~~~text
巨大な純損失が発表されたんだぜ
    ↓
全部がGPUの電気代なんだぜ？
    ↓
いや、債務などの評価額の変化も入っていたんだぜ！
~~~

**数字の桁に驚く前に、何を数えているのかを見るんだぜ。**

もちろん、会計上の損失が大きいからといって、設備投資や運用コストが小さいという意味ではないんだぜ。Anthropicは上半期だけで計算資源・インフラ関連に **89.45億ドル** を費用計上しているんだぜ。

## GoogleやMicrosoftまで「赤字」なのかよ、なんだぜ？

……**いや、大手企業の全社決算は普通に黒字なんだぜ。**

2026年7〜9月期の公式決算を見ると、

| 企業・部門 | 確認された利益（米ドル） |
| --- | ---: |
| Microsoft 全社・純利益 | **+366.29億ドル** |
| Alphabet 全社・純利益 | **約+262億ドル** |
| Google Cloud 部門・営業利益 | **+111.21億ドル** |
| Amazon AWS 部門・営業利益 | **+177.73億ドル** |
| Meta 全社・純利益 | **+98.60億ドル** |

おいおい、**「AIに投資している会社は全部赤字」なんて全然違うんだぜ！**

でも、ここで逆の勘違いもしちゃダメなんだぜ。

Google CloudやAWSは、LLMだけでなく普通のクラウドサービスやインフラも提供しているんだぜ。MicrosoftやMetaの全社利益にも既存の事業が含まれているんだぜ。

つまり、**会社全体が黒字だから、GeminiやCopilotやLlamaの単体サービスも黒字だと証明されたわけではない**んだぜ。

多くの企業はモデル単体の独立した損益を開示していないんだぜ。

## 黒字なのに、現金が減ることもあるんだぜ

さらにAmazonが面白いんだぜ。

2026年7〜9月期、AWS部門の営業利益は約 **177.73億ドル** だったんだぜ。

ところがAmazon全社の**直近12か月のフリーキャッシュフロー**は **マイナス424億ドル** だったんだぜ。

Amazonは、AIを中心とする設備投資の大幅な増加が大きな要因だと説明しているんだぜ。

Metaも2026年7〜9月期は**純利益98.60億ドルの黒字**なのに、同じ四半期の**フリーキャッシュフローはマイナス21.2億ドル**だったんだぜ。

**「利益があるのに現金が減ってるんだぜ？」**

そうなんだぜ。データセンターやGPUなどへの巨額投資は、会計上の利益と実際の現金の出入りに違う形で現れるんだぜ。

しかも、Amazonの数字は **直近12か月**、Metaの数字は **四半期**。期間の違う数字を単純比較して「どっちが赤字王なんだぜ？」とやるのも違うんだぜ。

## どうしてLLMはそんなにお金がかかるんだぜ？

原因を一言で「GPU代なんだぜ」で片付けると、半分しか説明できないんだぜ。

- **学習する費用** — 大量の計算資源、研究開発、データ、人材が必要なんだぜ。
- **推論する費用** — 利用者がモデルを呼ぶたびに計算資源を使うんだぜ。
- **設備投資** — GPU、電力、ネットワーク、データセンターを先に用意するんだぜ。
- **製品運用** — セキュリティ、営業、サポート、障害対応だってタダじゃないんだぜ。
- **会計の違い** — 株式報酬、転換社債評価、減価償却が最終利益に影響するんだぜ。

だから、一つのAPI呼び出しで粗利益が出ても、最先端モデルの研究費まで含めた会社全体では赤字になることがあるんだぜ。

逆に、AIの設備投資でフリーキャッシュフローがマイナスでも、既存事業から利益を出している会社もあるんだぜ。

## 「年商500億ドル！」も、ちょっと待つんだぜ

2026年10月には、OpenAIの9月時点の**年率換算売上（annualized revenue run rate）** が約500億ドルだとReutersが報じたんだぜ。

でも、これは直近の収益ペースを12か月へ換算した数字なんだぜ。

**実際に1年間で500億ドルを売り上げた、という意味ではない**んだぜ。

しかもOpenAIとAnthropicでは、クラウドパートナー経由の売上を集計に含めるかなどの基準も異なると報じられているんだぜ。

成長が速い会社ほど、**「実績」「年率換算」「将来予測」** を混ぜちゃいけないんだぜ。

## だからなんだぜ

LLM企業は確かに、とんでもない額を研究開発と計算資源に使っているんだぜ。

でも、

> **LLM企業はどこも赤字なんだぜ！**

と言い切ると、**Anthropicは2026年4〜6月期にGAAP営業黒字だった**という重要な事実を見落とすんだぜ。

一方で、どのモデルや製品が単体で利益を出しているかは、公開されていないものも多いんだぜ。

**「売上が増えた」も「純損失が巨額」も「クラウド部門が黒字」も全部本当になり得るんだぜ！**

そして最後に問われるのは、**先に注ぎ込む巨額の投資を、いつどうやって回収するのか**なんだぜ。

**おいおい、AIに仕事をさせる前に、AI自身の経理が一番忙しいんじゃないんだぜ！？**
