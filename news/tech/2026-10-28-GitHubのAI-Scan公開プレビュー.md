# AI Scanがリポジトリ全体を調べるんだぜ！でも料金には注意だぜ

- **掲載日**: 2026-10-29
- **出来事の日付**: 2026-10-28
- **区分**: Tech News / アプリケーションセキュリティ
- **対象**: GitHub AI Scan for repositories
- **提供状況**: パブリックプレビュー（正式提供ではないんだぜ）

## PRだけじゃなくて、リポジトリ全体を見るんだぜ！

GitHubが2026年10月28日、**AI Scanでリポジトリ全体を調べる機能**をパブリックプレビューとして発表したんだぜ！

先行していた**PRの変更部分を調べるAI Scan**とは別の設定で、リポジトリの**デフォルトブランチの最新コミット**を対象にスキャンするんだぜ。

CodeQLがまだ対応していない言語やフレームワークに目を向けられるほか、CodeQL対応言語でもルールベース解析が見逃す問題を探す、という狙いなんだぜ。結果は既存の**Code scanningアラート一覧**へ表示されるんだぜ。

## 見つけたら全部「脆弱性確定」なのか？ そんなわけないぜ！

エージェント型のスキャナーがリポジトリを探索し、脆弱性がありそうな箇所を重点的に見るんだぜ。スキャンの実行時間は固定の予算で制限され、CodeQLがすでに報告する問題は重複報告しない設計なんだぜ。

ただし、**AIによる検出には誤検知・見逃しの可能性がある**んだぜ。結果は修正や検証の出発点として使うべきで、見つかったというだけで悪用や被害が確認されたわけではないぜ。

修正PRをマージしてもアラートは自動で閉じないんだぜ。**再スキャンして修正を確認する**必要があるぜ。

## 個人の公開リポジトリも対象。でも請求条件を見逃すなよ！

発表時点の主な条件はこうなんだぜ。

- **個人アカウント**: 公開リポジトリは対象、個人所有の非公開リポジトリは対象外なんだぜ。
- **組織所有**: 公開リポジトリは対象。非公開・内部リポジトリではGitHub Code SecurityまたはGitHub Advanced Securityが必要なんだぜ。
- **利用形態**: github.comとGitHub Enterprise Cloud with data residencyで利用できるんだぜ。Copilotライセンスは不要なんだぜ。
- **費用**: **Code Security AI creditsを消費する**んだぜ。個人の公開リポジトリは、条件によって個人アカウントへ請求されるんだぜ。無料で無制限に回せるわけじゃないぜ。

特に最後が大切なんだぜ。**「公開リポジトリだから無料でスキャンしまくれる」は危険な思い込み**なんだぜ。予算設定と請求先を確認してから有効にするんだぜ。

## だからなんだぜ

ルールベースの静的解析とAI解析を組み合わせて、コードの別の角度から問題を探せるようになるんだぜ。一方で、プレビューの制約、料金、検出結果の確認は開発者の仕事として残るんだぜ。

脆弱性を見つける道具が増えるのはうれしいぜ。でも**ツールを入れただけでセキュリティが完成するわけじゃない**んだぜ！
