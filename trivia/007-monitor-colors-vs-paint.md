# #007 モニターの発色ってな、実は絵の具と違うんだぜ

色を混ぜるって聞くと、

> **赤と青を混ぜたら紫なんだぜ**

みたいな、絵の具の感覚を思い浮かべることが多いんだぜ。

でもな。

**モニターの色の作り方は、絵の具とは仕組みが逆なんだぜ。**

### モニターは「光を足す」んだぜ

モニターは自分で光を出してるんだぜ。

基本になるのは、

```text
Red
Green
Blue
```

つまり **RGB** なんだぜ。

この3色の光を足していくんだぜ。

だから、

```text
赤 + 緑 = 黄
緑 + 青 = シアン
青 + 赤 = マゼンタ
赤 + 緑 + 青 = 白
```

になるんだぜ。

これを **加法混色** って呼ぶんだぜ。

つまりモニターでは、

> **光を足せば足すほど明るくなるんだぜ。**

なんだぜ。

全部消したら黒なんだぜ。

全部出したら白なんだぜ。

### 絵の具は「光を引く」んだぜ

一方、絵の具は自分で光ってないんだぜ。

外から来た光の一部を吸収して、残った光を反射してるんだぜ。

だから絵の具を混ぜるっていうのは、

> **反射できる光をどんどん減らしていくんだぜ。**

に近いんだぜ。

印刷ではよく、

```text
Cyan
Magenta
Yellow
```

つまり **CMY** を使うんだぜ。

実際の印刷では黒をきれいに出すために **K** を足して、CMYKになるんだぜ。

これは **減法混色** なんだぜ。

つまり絵の具やインクでは、

> **混ぜれば混ぜるほど暗くなるんだぜ。**

なんだぜ。

### 白と黒の作り方が真逆なんだぜ

ここが一番わかりやすいんだぜ。

モニターでは、

```text
光なし = 黒
RGB全部オン = 白
```

なんだぜ。

でも紙とインクでは、

```text
インクなし = 紙の白
インクを重ねる = 黒に近づく
```

なんだぜ。

つまり、

> **モニターの白は「全部出してる」んだぜ。**
>
> **紙の白は「何も塗ってない」んだぜ。**

なんだぜ。

同じ「白」でも作り方が正反対なんだぜ。

### だから画面の色と印刷の色は一致しないんだぜ

モニターで見た鮮やかな色が、

> **印刷したらなんかくすんだんだぜ**

ってことがあるんだぜ。

これは故障じゃないんだぜ。

モニターはRGBの光で作れる色を出していて、印刷はインクと紙の反射で色を作ってるんだぜ。

そもそも **作れる色の範囲が違う** んだぜ。

この「その装置で表現できる色の範囲」を **色域、gamut** って呼ぶんだぜ。

だから、

```text
画面では出せるんだぜ
でも印刷では出せないんだぜ
```

みたいな色も普通にあるんだぜ。

### 「三原色」って一個じゃないんだぜ

学校で「色の三原色」って習うと、

> **三原色って決まった3色があるんだぜ**

と思いがちなんだぜ。

でも実際には、

```text
光の三原色 → RGB
色材の三原色 → CMY
```

みたいに、何を混ぜるかで話が変わるんだぜ。

つまり、

> **赤・青・黄を混ぜる話と、RGBモニターの話を同じルールで考えると混乱するんだぜ。**

なんだぜ。

### だからなんだぜ

モニターの色は、

> **小さい色付きの光を塗ってるんだぜ**

じゃないんだぜ。

正しくは、

> **赤・緑・青の光を足し合わせて、目に色として感じさせてるんだぜ。**

なんだぜ。

絵の具は、

> **光を足してるんじゃなくて、反射する光を削ってるんだぜ。**

なんだぜ。

同じ「色を混ぜる」でも、

**モニターと絵の具では、物理的にはほぼ逆のことをやってるんだぜ。**
